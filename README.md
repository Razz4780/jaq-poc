PoC for using [jaq](https://github.com/01mf02/jaq) with time and memory limits.

* `safejaq` - contains a wrapper that allows for evaluating JAQ filters with configurable limits
* `safejaq-evaluator` - dependency of `safejaq`, contains implementation of the evaluator command
* `safejaq-types` - dependency of both `safejaq` and `safejaq-evaluator`, contains definitions of common types
